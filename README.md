# AutoClicker Plus

一个适用于 Windows 的自动点击器，支持全局快捷键、前台点击和后台窗口点击。

## 特性

- 全局快捷键一键开始 / 停止
- 支持快捷键录制，兼容 `F1-F12` 和组合键
- 点击间隔使用毫秒配置，适合高频点击
- 支持左键、右键、中键
- 前台模式
  - 鼠标当前位置
  - 拖拽框选区域
- 后台模式
  - 选择正在运行的软件窗口
  - 选择窗口内点击位置
  - 选择窗口内点击区域
  - 区域支持随机点或中心点
- 自动保存配置
- 内置程序图标与打包脚本

## 下载安装

### 源码运行

```bash
py -m pip install -r requirements.txt
py main.py
```

### 可执行文件

如果你已经下载了发布版，可以直接运行：

```bash
dist\AutoClicker.exe
```

## 使用方法

1. 点击 `录制快捷键`
2. 按下需要的快捷键后松开
3. 设置点击间隔，单位为毫秒
4. 选择鼠标按键
5. 选择工作模式
   - 前台动态位置：点击时读取鼠标当前所在位置
   - 前台区域：点击 `开始框选区域` 后拖拽选区
   - 后台位置：点击 `刷新窗口列表`，选择窗口，再点击 `选择窗口点击位置`
   - 后台区域：点击 `选择窗口点击区域`，拖拽出窗口客户区内的区域
6. 按一次快捷键开始，再按一次同一个快捷键停止

## 后台点击说明

后台点击通过 Windows 消息机制实现，适合大多数普通桌面程序。

注意：

- 部分游戏、DirectX 程序、特殊控件或受保护窗口可能不响应
- 目标窗口关闭后，程序会提示重新选择
- 后台位置与后台区域会分别保存，不会互相覆盖

## 打包

项目提供一键打包脚本：

```bash
.\build.ps1
```

打包产物位于：

```text
dist\AutoClicker.exe
```
