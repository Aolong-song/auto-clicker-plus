# 自动点击器项目

## 功能说明
- 全局快捷键一键切换开始/结束
- 快捷键录制模式：点击按钮后按下按键或组合键自动保存，支持 `F1-F12`
- 点击间隔使用毫秒（ms）配置，支持高频点击
- 支持左键、右键、中键点击
- 支持前台点击模式
  - 鼠标当前位置（动态，每次触发时读取）
  - 拖拽框选区域
- 支持后台点击模式
  - 从当前运行的软件窗口中选择一个目标窗口
  - 后台支持“位置”与“区域”两种点击对象
  - 区域点击支持“随机点”和“中心点”
- 自动保存配置到 `config.json`

## 环境要求
- Python 3.9+
- Windows 桌面环境

## 安装依赖
```bash
cd auto_clicker_project
py -m pip install -r requirements.txt
```

如果你的环境里有 `python` 命令，也可以：
```bash
python -m pip install -r requirements.txt
```

## 运行
```bash
cd auto_clicker_project
py main.py
```

或者：
```bash
python main.py
```

## 使用步骤
1. 点击 `录制快捷键`，按下你想要的快捷键
2. 设置 `点击间隔（毫秒）`
3. 选择点击按键
4. 选择点击模式
   - 前台动态位置：无需额外操作，定时触发时点击当前鼠标位置
   - 前台区域模式：点击 `开始框选区域` 后拖拽选区
   - 后台位置模式：点击 `刷新窗口列表`，选中一个正在运行的软件，再点击 `选择窗口点击位置`
   - 后台区域模式：点击 `选择窗口点击区域`，拖拽出窗口内区域
5. 按快捷键开始，再按同一个快捷键结束

## 注意事项
- 首次使用全局快捷键时，系统可能会请求输入或辅助功能权限
- 框选区域时按 `Esc` 可以取消
- 后台点击依赖窗口消息机制，部分游戏、DirectX 程序或特殊软件可能不响应
- 背景模式下，位置与区域会分别保存，切换模式后不会互相覆盖

## 打包为 exe
项目已提供图标资源 `assets/app.ico` 和 logo `assets/logo.png`。

一键打包：
```bash
cd auto_clicker_project
.\build.ps1
```

打包产物会输出到 `dist\AutoClicker.exe`。
