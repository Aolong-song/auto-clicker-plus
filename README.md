# AutoClicker

一个支持全局快捷键、前台点击、后台窗口点击的 Windows 自动点击器。

## 主要功能

- 全局快捷键一键开始/停止
- 快捷键录制模式，支持 `F1-F12` 和组合键
- 点击间隔使用毫秒配置，适合高频点击
- 支持左键、右键、中键
- 前台模式
  - 鼠标当前位置
  - 拖拽框选区域
- 后台模式
  - 选择正在运行的软件窗口
  - 选择窗口内点击位置
  - 选择窗口内点击区域
  - 区域支持随机点或中心点
- 自动保存配置
- 已内置程序图标和启动器打包脚本

## 适用场景

- 重复点击操作
- 游戏或工具软件中的重复动作
- 需要在不抢占鼠标的情况下进行后台定点点击

## 下载与运行

### 直接运行源码

```bash
cd auto_clicker_project
py -m pip install -r requirements.txt
py main.py
```

### 打包版

如果你只想拿可执行文件，直接运行：

```bash
dist\AutoClicker.exe
```

## 使用说明

1. 点击 `录制快捷键`
2. 按下你想要的快捷键，然后松开
3. 设置点击间隔，单位为毫秒
4. 选择鼠标按键
5. 选择点击模式
   - 前台动态位置：定时触发时点击鼠标当前所在位置
   - 前台区域：点击 `开始框选区域` 后拖拽选区
   - 后台位置：点击 `刷新窗口列表`，选中一个窗口，再点击 `选择窗口点击位置`
   - 后台区域：点击 `选择窗口点击区域`，拖拽出窗口客户区内的区域
6. 按一次快捷键开始，再按一次同一快捷键停止

## 后台点击说明

- 后台点击通过 Windows 窗口消息实现
- 对大多数普通桌面程序有效
- 部分游戏、DirectX 程序、特殊控件可能不响应
- 目标窗口关闭后，程序会提示重新选择

## 打包

项目提供一键打包脚本和图标资源。

```bash
cd auto_clicker_project
.\build.ps1
```

```bash
dist\AutoClicker.exe
```
